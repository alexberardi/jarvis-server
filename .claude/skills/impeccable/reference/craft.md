# Craft (deprecated alias)

`craft` is a deprecated alias for an ordinary request to make new visual work. It adds no setup, interview, checkpoint, tool, or quality behavior. Apply SKILL.md's normal routing, then follow [new-work.md](new-work.md) for visual authority, world and surface decisions, implementation, and finish. PRODUCT.md does not exist in this repo: do not stop to create it (use [init.md](init.md) only when the user asks); read PRODUCT.md / DESIGN.md if they exist, and otherwise read `web/admin/src/index.css`, `web/admin/src/theme/` and the existing components.

Do not tell users they need to invoke `craft`. Natural requests such as “build this feature,” “make a landing page,” or “redesign this screen” use the same flow.
