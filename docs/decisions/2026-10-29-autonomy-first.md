# Autonomy first: the element layer serves computer tasks

- **Date:** 2026-10-29 (user)

The goal is not driving the computer by voice but Jarvis doing things on it by itself: summarize
a Wikipedia page into a LibreOffice Writer document, run the budget report in Calc. The element
layer is the building blocks for those computer tasks. Voice steering ("click Bold") is a side
door onto the same blocks: interactions that don't work by voice are acceptable as long as the
autonomous goal is reached.

So, after the 2026-10-29 voice test: voice-steering polish is parked, and the next work is
measuring and fixing real computer tasks built from the user's examples, each scored from the
result it leaves (the saved document or sheet), not the model's words.
