# Multi-step requests said to a computer start there at once, attended

- **Date:** 2026-10-25 (user)

The north star moves from "talk instead of using the mouse" to **deprecating the mouse
altogether**, including multi-step work said once ("open Word and write my resume, ask me
questions along the way"; "write an email to James"; "open spreadsheet X and run the monthly
budget summary workflow on it"). Such requests run in the computer-task loop
([COMPUTER-CONTROL.md](../agent/COMPUTER-CONTROL.md)), which lifts the "single bounded actions,
no planning" rule of [2026-10-24-desktop-voice-actions.md](2026-10-24-desktop-voice-actions.md)
for them; single actions keep the direct path.

When computer control is on and a multi-step request is said to a computer, the task starts on
that computer immediately and attended: no plan card and no "Tap Run" on the phone, since the
user is there and asked. The loop's rules apply as before (C2, C8; C9 pauses on the user's
input). Tasks started elsewhere, or with nobody at the computer, keep the phone path. Spec and
question queue: [VOICE-FLOWS.md](../agent/VOICE-FLOWS.md).
